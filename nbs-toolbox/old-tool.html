舊工具箱

Original Excel-based Toolbox Index

工具箱最早是用 Excel 建立的：一個含有 VBA 巨集、共 8 個工作表的 xlsm 檔案，收錄了 131 項流域自然解方規劃與評估可用的工具。這裡提供的是當時搭配 Excel 檔另外做的網頁版「工具索引」簡易查詢介面，更方便查詢。

2024・計畫原始版本 131 項工具索引 現已由新工具箱的「工具箱資料庫」取代
Original Structure

Excel 檔案裡有什麼

「自然解方工具箱」xlsm 檔案共有 8 個工作表（sheets），前 4 個是工具箱的核心內容，後 4 個是補充資訊：

NbS 導入流程

提供自然解方專案啟動步驟的流程圖，說明各階段需考量的要點。

展示工具

自然解方簡表(一)(二)(三) 三份展示模板，用於檢視專案規劃是否涵蓋 IUCN 自然解方指引與要素，也可作為對外說明的展示工具。

工具索引／工具箱清單

本計畫收集工具的索引與簡要說明，搭配一個簡易查詢界面，方便依類別或關鍵字查詢工具說明。

補充資訊（4 個工作表）

IWRM Tools 綜合流域治理工具清單、蘭陽溪水系治理規劃 110 年課題整理、Deeksha (2022) 生態系服務評估模型盤點、臺灣河川流域及類群特色摘錄。

Tool Index

工具分類：A／B／C／D

工具索引依照下列四大項分類，這套分類架構也延續到新工具箱的「工具箱資料庫」裡：

A

環境友善指引

收集國際永續利用生態系統之策略、評估指引。

B

管理與評估

分為兩子項目：(B1) 指標與模式，收集水文／水理模式、生態系服務評估指標等；(B2) 決策支援系統，包含相關決策輔助工具、框架。

C

案例與干預

分為兩子項目：(C1) 干預手段，流域中可採用的獨立干預手段；(C2) 專案，研究案例、整合報告或專書。

D

資料庫

包含基礎資料庫以及國際相關工具箱（如 IWRM Tools、ESVD 生態系服務評估資料庫）。

Launch

開啟工具索引查詢介面

這是當時搭配 Excel 檔另外做的網頁版查詢介面：展開工具類別／子類別瀏覽工具索引，或直接用工具編號、名稱查詢說明。

舊版查詢介面

工具索引查詢

瀏覽工具類別、子類別與對應工具清單，用編號或名稱查詢工具的簡要說明。
