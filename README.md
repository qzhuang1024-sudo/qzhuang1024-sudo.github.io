# qzhuang1024-sudo.github.io

Personal academic website of **Qun-Zhan Huang** (PhD candidate, National Taiwan University) — pore-scale wetting-liquid displacement in micromodels and ecohydrological separation.

Live site: https://qzhuang1024-sudo.github.io/

## Structure
| File | Content |
|---|---|
| `index.html` | Home: photo, short bio, interests, recent papers |
| `about.html` | Background, methods, contact |
| `research.html` | Dissertation chapters and related work |
| `publications.html` | Full publication list |
| `projects.html` | Research projects |
| `cv.html` | CV summary + PDF download |
| `assets/css/style.css` | Shared styles (auto light/dark) |
| `assets/images/profile.jpg` | Profile photo |
| `assets/pdf/CV.pdf` | Full CV |

## Updating
- Plain HTML/CSS, no build step. Edit a page, commit, push — GitHub Pages redeploys in ~1 min.
- Search for `TODO` to find placeholders still to fill in.
- Navigation is repeated in each page's `<nav>`; update all six files if you add a page.
