淹灌串流模式

43 坵田塊以田埂缺口串接，3 條圳路與 1 座水池供水

每坵田視為一個水箱，容量為土壤可蓄水量 (蓄水深度 × 孔隙率) 加上湛水深。上游來水先補足入滲、蒸發散與尚未填滿的容量；田塊蓄滿後，多餘的水從田埂缺口溢流，依分水比例流向下一坵田，最後由 S20 排入溪流。

S_tmp = S + Q_in(t+1) + (P − ET − K)·A S = max(S_tmp, 0) (土壤水最低為 0，不出現負值) Q_out = max(S − S_max, 0)，S ← S − Q_out S_max = A·(d·n + h_p)

假設：田內儲水量 S 不低於 0。田面乾燥後，實際蒸發散會隨土壤含水量下降，不會持續以固定的 Kc·PET 扣除；同時深層土壤仍保持濕潤，可藉毛細作用向上補給表層土壤，因此儲水量不會無限制減少。設定 S ≥ 0 可避免乾燥田塊累積不存在的「水分虧缺」，使下游淹水時間不被高估。

S：田內儲水量，土壤水 + 湛水 (m³)；Q_in、Q_out：入流與溢流 (m³/day)；A：田塊面積 (m²)；P：降雨、ET：蒸發散 (m/day)；K：入滲率 (m/day)；d：土壤蓄水深度、n：孔隙率、h_p：湛水深 (m)。

梯田灌溉需水模式

由田塊需水沿水路反推至三個取水口

理想操作下田間湛水深維持固定，除整田、曬田與收割前停灌外，每日田間水平衡為：

灌溉 + 有效降雨 − (滲漏 + 蒸發散) = 0 有效降雨 = min(滲漏 + 蒸發散, 降雨) 每日需灌水量 = (滲漏 + 蒸發散) − 有效降雨 [mm/day]

田塊 j 的總需水 TD_j 除了自身需水 D_j，還要轉送給下游田塊 k；若 j 的溢流以比例 r_k 流入 k (依田埂缺口數分擔)：

TD_j − Σ_k r_k·TD_k = D_j [C][TD] = [D] ⇒ [TD] = [C]⁻¹[D]

直接由渠道水門引水的田塊，其 TD 即為該水門需供水量：圳路1 = TD(N1)；圳路2 = TD(水池) + TD(S1-1) + ½·TD(S2)；圳路3 = TD(S0-1)。

D_j = 每日需灌水量 × 田塊面積 / 1000 (m³/day)；蒸發散 = Kc × PET；Kc 水稻作物係數隨生育期 0.5 → 1.3 → 0.7；TD、D 單位 m³/day (cmd)。
